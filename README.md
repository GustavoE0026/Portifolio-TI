# Portfólio de Tecnologia da Informação — Gustavo Eduardo

Este repositório apresenta projetos práticos desenvolvidos durante meus estudos e experiências em Tecnologia da Informação, com foco em infraestrutura, servidores, desenvolvimento Java e aplicações web.

## Projetos

### Servidor TrueNAS

Projeto de implantação e administração de um servidor TrueNAS para armazenamento centralizado e serviços de rede.

Principais atividades:

- instalação e configuração do TrueNAS;
- organização de discos, pools e datasets;
- criação de compartilhamentos SMB;
- configuração de usuários e permissões individuais;
- acesso aos arquivos pelo Windows e macOS;
- configuração e diagnóstico do Tailscale;
- estudos para implantação de PXE Boot;
- testes com máquinas virtuais e aplicativos;
- análise de discos com SMART e diagnóstico de falhas;
- documentação dos problemas encontrados e das soluções aplicadas.

[Acessar documentação do projeto TrueNAS](truenas/README.md)

### Java Web — Cadastro de Clientes

Aplicação Java Web criada para demonstrar o fluxo entre formulário HTML, requisição HTTP, Servlet, processamento e resposta ao usuário.

Tecnologias:

- Java;
- Jakarta Servlet;
- HTML;
- Apache Tomcat;
- Eclipse IDE;
- Maven.

[Acessar projeto Java Web](java/cadastro-clientes-servlet/README.md)
